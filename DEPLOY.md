# Deploy in 5 minutes (Render, free)
1. Create a GitHub repo and upload this folder (.env is ignored; never upload your key).
2. render.com > New > Blueprint > pick the repo > Apply.
3. When asked, paste GEMINI_API_KEY (from aistudio.google.com/apikey).
4. Wait for the deploy, then open the onrender.com URL. Header pill must say "Gemma live".
